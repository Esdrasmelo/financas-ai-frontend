# Índice de funcionalidades

Adicione aqui documentação por funcionalidade ou tela, no padrão `NN-NomeTema.md` (ex.: `02-Dashboard.md`).

Rotas principais (App Router):

- `/` — entrada
- `/dashboard` — visão geral
- `/planning` — planejamento / orçamento
- `/entries`, `/fixed-expenses`, `/categories` — lançamentos e cadastros
- `/credit-cards`, `/statements`, `/purchases` — cartão e faturas
